## 菜品结构

```python
{
    "id": "M01",              # 编号
    "name": "Beef burger",    # 菜名
    "category": "main food",  # 分类
    "price": 15.0,            # 单价
    "stock": 500,             # 库存，结账后自动扣减
    "describe": "Handmade beef patties.",
    "available": True,        # False = 停售
}
```

编号前缀：`M` 主食、`D` 饮品、`S` 小吃、`W` 甜点。

## 功能说明

**1. 浏览菜单** — 按主食、饮品、甜点、小吃四个分类分表展示，列出编号、名称、价格、库存和状态

**2. 搜索菜品**
- 按名称：模糊匹配，输入 `burger` 能找到 `Beef burger`，不区分大小写
- 按价格区间：输入最低价和最高价筛选
- 按分类：输入分类名片段，如 `snack`

**3. 购物车** — 加菜时校验：是否停售、库存还剩多少、数量是否合法；支持改数量、删除、按分类汇总消费。

**4. 推荐** — 用 `if` 判断：
- 车是空的，推荐招牌主食 + 可乐 + 甜点
- 有炸鸡且没可乐，推荐可乐
- 有主食没饮品，推荐柠檬水
- 有主食没甜点，推荐提拉米苏
- 有甜点没饮品，推荐咖啡
- 只有小吃或甜点，推荐主食
- 只有饮品，推荐薯条

**5. 结账** — 先检验购物车→ 显示明细和分类汇总>>报价确认>>输入收款金额>>计算找零>>打印小票>>扣库存>>清空购物车>>订单号++。

小票包含订单号、时间、明细、小计、合计、实付、找零。

**6. 输入校验** — 所有键盘输入通过同一模块处理，输入字母、超出范围、直接回车都会被重问
